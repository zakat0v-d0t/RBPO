**Лабораторная работа №3**  
Проект представляет собой бэкенд для библиотеки (абонемент).  
   
 В этой работе перевели проект с H2 на PostgreSQL, вынесли конфиги в .env, добавили пользователя с ограниченными правами, настроили ограничения в таблицах и сделали бизнес-логику (выдача/возврат книг, лист ожидания).  
**Сущности**  
- User — читатели (имя, почта, телефон).  
- BookEdition — книги (название, автор, ISBN).  
- Copy — конкретные экземпляры книги (инвентарный номер, состояние).  
- Loan — выдача экземпляра читателю (дата выдачи и возврата).  
- WaitingRequest — очередь на книгу, если все копии на руках.  
**Бизнес-операции**  
- Выдача книги (POST /api/loans/issue) — нельзя выдать экземпляр, если он уже у кого-то на руках.  
- Возврат книги (POST /api/loans/{id}/return) — возвращает книгу и автоматически переводит первую заявку из очереди ожидания в статус FULFILLED.  
- Запись в очередь (POST /api/waiting-requests/subscribe) — встать в лист ожидания на книгу.  
- Список свободных копий (GET /api/copies/available).
